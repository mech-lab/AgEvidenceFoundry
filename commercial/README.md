# Commercial Substrate

`commercial/` contains the reusable company-formation grammar that sits above the AgEvidence product substrate.

It defines shared schemas, contact-role vocabulary, scoring defaults, templates, and cross-portfolio account intelligence. Ventures keep their own commercial choices under `ventures/<venture>/`.

The source dossiers are treated as inputs to structured operating files. PDFs and decks explain decisions; YAML files drive validation, scoring, generation, and extraction.
