# Foundry Boundary

AgEvidence owns the evidence substrate. Foundry owns company formation. Individual companies own vertical differentiation.

## The Rule

```text
Generic -> upstream
Factory-specific -> Foundry
Vertical -> venture pack
Proprietary -> company repo
```

## Practical Test

If a concept must be understood by many independent evidence-native agriculture companies, propose it upstream in AgEvidence.

If a concept helps create, validate, demo, or extract companies, keep it in Foundry.

If a concept is specific to a buyer, market, method, source system, or claim type, keep it in `ventures/<venture>/`.

If a concept is a private model, customer workflow, pricing strategy, or operating advantage for one company after formation, keep it out of Foundry and put it in the standalone company repo.
