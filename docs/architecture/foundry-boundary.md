# Foundry Boundary

AgEvidence owns the evidence substrate. Foundry owns company formation. Individual ventures own their vertical operating thesis. The final corporate boundary is a per-venture architecture decision.

## The Rule

```text
Generic / trust infrastructure -> upstream
Factory-specific machinery -> Foundry
Vertical operating thesis -> venture pack
Reusable cross-vertical IP -> parent
Truly vertical proprietary advantage -> allocated by formation_architecture
Customer, data, and improvement rights -> allocated venture by venture
```

## Practical Test

If a concept must be understood by many independent evidence-native agriculture companies, propose it upstream in AgEvidence.

If a concept helps create, validate, demo, or extract companies, keep it in Foundry.

If a concept is specific to a buyer, market, method, source system, or claim type, keep it in `ventures/<venture>/`.

If a concept is a private model, customer workflow, pricing strategy, or operating advantage for one company after formation, allocate it according to that venture's `formation_architecture`. Independent spinout is one valid allocation, not the default answer for every venture.
