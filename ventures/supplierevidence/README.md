# SupplierEvidence Company Pack

SupplierEvidence configures AgEvidence for supplier programs, buyer requirements, reporting periods, Scope 3 claims, insetting claims, supplier evidence passports, corporate evidence packages, and assurance exports.

The product pack lives in `product/`. Commercial operating files live in `brand/`, `gtm/`, `accounts/`, `pitch/`, `research/`, and `formation/`. The current customer-facing working brand is SourceRelay.
