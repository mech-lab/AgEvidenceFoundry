# MethaneProof Company Pack

MethaneProof configures AgEvidence for methane intervention reliance.

It owns intervention vocabulary, additive lot requirements, methane measurements, model support, and the methane evidence statement template.

It does not own generic evidence storage, API authentication, artifact hashing, signature semantics, verifier implementation, SDKs, or Rails tenancy.

The product pack lives in `product/`. Commercial operating files live in `brand/`, `gtm/`, `accounts/`, `pitch/`, `research/`, and `formation/`.
